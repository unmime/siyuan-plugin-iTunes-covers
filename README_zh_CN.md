# iTunes cover get

在思源笔记里搜书、音乐专辑、剧集的官方封面，**插入到正文**，或者**设为文档图标**。数据来自 Apple iTunes Search API，不用申请 key。

中文关键词直接搜就行（「三体」「球状闪电」都能命中）。书和专辑封面多是 1:1，剧集是 16:9，面板里用统一容器展示，不会互相挤变形。

## 用法

入口是一个**五角星图标**，出现在这几处，任选其一：

- **顶栏** —— 右上角工具栏里的星形按钮
- **表情面板** —— 点文档图标打开表情面板，顶部图标排最后多了一颗星，就地切换，自带搜索框和小分类。**动作跟着打开方式走**：
  - 从**文档标题图标**打开 → 选中封面**替换文档图标**
  - 从**正文插入表情**打开 → 选中封面**插入到光标处**
- **底栏** —— 编辑器面包屑里的星形（主题把面包屑移到底部时，就在那条胶囊里）
- **命令面板** —— 「打开 iTunes cover get」。默认没绑快捷键，需要的话去 设置 → 快捷键 自行绑定

另外右键点击文档标题左侧的图标，菜单里也有入口。

面板打开时光标已经在搜索框。这是远程搜索接口，所以**回车才查**，不会边打字边请求；默认停在「全部」，同时查书 / 专辑 / 剧集各 12 条，用 chips 可以只看一类（36 条）。

- **左键点击卡片** —— 封面插入到正文光标处
- **悬停后点右上角按钮** —— 设为当前文档的图标
- **右键卡片** —— 菜单里两种操作都能选
- **Esc** —— 先清空搜索框，再按一次关面板

## 几个边界

- **电影搜不到。** Apple 已经停供 iTunes 电影数据，剧集也只认 `tvSeason`；有些剧在美区本来就没收录（比如 Stranger Things），搜「全部」时剧集一栏就是空。
- **偶尔提示「搜索失败」。** iTunes 接口会限流、超时，等几秒重试即可。
- 搜索固定走美国区（`country=us`），`cn` 区拿不到电子书数据。
- 插入正文时封面会存到 `assets/iTunes-covers/`，随文档一起导出，不会断图。

## 实现说明

设为文档图标时，封面写到 `data/emojis/iTunes-covers/`，和思源自定义表情同目录，随工作区同步、多设备可用。插件按需写入：只有你实际选中的封面才会下载，同一部作品重复使用也不会重复上传。
